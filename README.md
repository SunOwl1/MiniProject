<h1 align="center">Числовая угадайка</h1>

Это простая консольная игра, в которой пользователь пытается угадать случайно загаданное число в заданном диапазоне.

Как работает программа
- Пользователь вводит максимальное число диапазона.
- Программа загадывает случайное число от 1 до указанного значения.
- Игрок вводит свои попытки
---
Вывод на экран
- Число больше загаданного, число меньше загаданного или что ввод некорректный.
- Игра продолжается, пока число не будет угадано.
- Показывается количество попыток.
- Можно сыграть ещё раз.
